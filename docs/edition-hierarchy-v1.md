# 专辑 → 发行版本 · 两级目录

2026-10-21。本次仅更新本地项目，保留照片开屏、黑色介绍区、`/archive` 及写真/影像功能，不部署公网。

## 新增与浏览

1. 在 `/contributor/albums` 点“新增专辑”，只填写专辑名称、艺人和基本介绍；创建后进入该专辑的版本目录。
2. 在专辑中点“添加版本”，再填写版本名称、厂牌、编号、载体、日期、地区、条码、版本说明、购买渠道、曲目、封面/歌词纸、无损音源与来源。
3. 每个版本有独立编辑地址。修改版本 A 的曲目、图片或音源，不会改写版本 B。原有多人署名、私人歌词、无损编码检查、曲目与音源双向跳转继续可用。
4. 每个版本的封面、歌词纸和内页合计最多六张；音源不占图片名额。图片与音源自动关联当前版本，不能从版本 A 的上传入口覆盖版本 B 的文件。
5. 版本目录用细线、留白和封面展示各版本的厂牌、编号、载体、日期与曲目数。可上移/下移版本；排在第一位的版本决定一级专辑目录封面。第一项没有封面时，不会借用第二项的图片。

公开本地浏览路径：

```text
/discography                                    第一级：专辑
/discography/[slug]                             第二级：该专辑的版本目录
/discography/[slug]/editions/[editionId]         具体版本资料、曲目和已获准公开的图片
```

Contributor 路径：

```text
/contributor/albums/new                         创建专辑
/contributor/albums/[id]                        版本目录 / 调整顺序
/contributor/albums/[id]/edit                   专辑基本资料与审核
/contributor/albums/[id]/editions/new            添加版本
/contributor/albums/[id]/editions/[editionId]/edit
/contributor/albums/[id]/editions/[editionId]/preview
```

审核继续以整张专辑及其全部已保存版本为单位，未新增独立的版本审批角色。工作稿修改和排序不会覆盖旧的公开快照；批准后，目录与首版封面一起更新。Contributor 可看私人封面；匿名公开页仅显示已批准且确认公开授权的图片，音源仍只在本机私有保存。

## 旧数据与迁移

数据库首次打开时执行一次结构迁移：保留专辑 ID、slug、原文件与修订；旧共用曲目转为各个现有版本的独立资料，原本没有版本的曲目/媒体收纳到“待整理版本”。旧无归属媒体放在第一项，已有明确版本关联保持原样。未知载体仍留空，不推测 CD/LP。

迁移会保留原始修订快照并增加迁移记录与修订号，旧编辑页面需要刷新以免覆盖。实际项目同步前已使用 SQLite 在线备份保存一致快照到 `data/backups/before-edition-hierarchy-20261021-124707.sqlite`；原图片/音源不搬动、不删除。`data/` 仍忽略提交且排除生产打包。
