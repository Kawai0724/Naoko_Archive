# 专辑按发行日期排序

公开唱片目录、相关专辑与 Contributor 专辑清单统一从早到晚排列，比较完整的年/月/日，而非只比较年份。优先使用专辑首次发行日期；未填或非法时，取有效版本日期中最早的一项；完全未知的日期放在末尾。只知年/月的日期保留原精度，排序时同一年内先列较粗精度记录。

同日按稳定 ID 排序，创建时间、编辑时间、标题和普通资料修改不改变位置。版本内部顺序仍由成员手动安排，一级封面仍来自第一个版本。排序仅发生在读取时，不改写数据库日期、版本次序或历史。公开目录使用已批准快照，未审日期修改只影响作者/管理员看到的工作稿顺序。清单的年份和搜索采用相同的日期回退规则。

验证：60 项测试、typecheck、build；新增覆盖同年不同月日、部分精度、无效/未知日期、同日稳定顺序、普通编辑后不跳位、版本回退不改变版本顺序、公开快照隔离和资料库重新打开。真实 HTTP 验收使用本机 3416 全新临时目录与测试密码 `album-order-test-password`，运行 `node scripts/verify-album-order.mjs`。测试创建/审核五条明确的 ORDER_* 测试数据，不能指向真实资料目录；结果见 `docs/album-order-http-qa.json`。

部署先备份服务器 SQLite，只更新代码并运行检查、构建及重启现有系统级服务。不开放公网，不上传或复制生产资料，不用真实专辑测试编辑和审核。
