# 社区成员与管理员申请

## 使用

- `/members`：访客可查看所有已获批、正常启用的成员，显示用户名、管理员/贡献者角色及加入日期。入口位于页脚“社区成员”。待审、拒绝、停用、注销账号不进入访客目录。
- `/contributor/members`：工作台及共建导航均有“社区成员”。普通获批成员可填写申请说明，点击“申请成为管理员”。申请期间显示状态，不可重复提交；拒绝后显示回复，可补充说明重新申请。
- `/contributor/admin` → **管理员申请**：管理员查看、批准或拒绝申请，可填写回复。批准后现有会话在下次请求立即读取新角色，无需修改密码。普通成员看不到他人的申请，也不能直接改角色或自行批准。
- `/contributor/members` 的管理员视图保留全部账号、状态、邀请、停用/启用，并增加 **注销用户**。必须在确认框填写该账号完整用户名。自己不能注销自己，服务器同时保护最后一位正常管理员。

## 注销语义

这是关闭网站账号，并非删除历史资料：保留数据库账号及原用户名、密码哈希、投稿、专辑、版本、媒体关联、所有权、修订与审计记录；原用户名不可重复注册。账号立即失去登录/编辑/上传权限，全部会话删除，其创建但未使用的邀请撤销。待审注册和管理员申请转为拒绝，防止旧审核重新启用账号。

已注销账号不能通过“启用”恢复，前端也不再显示操作按钮。普通“停用”功能继续保留，可用于暂时限制成员。不会自动注销任何既有用户。

## 持久化和权限

在 SQLite 追加 `contributor_users.closed_at` 和 `contributor_admin_applications`。保留现有全部账号及角色（包括已升级的 `Sentimental_Velvet_Rain`）、密码、会话与资料。申请、审批、账号角色、注销、会话撤销、邀请撤销及审计均在事务中更新；申请重提与审批使用修订号防止过期及重复操作。

公开投影严格只有 username、role、created_at，不输出数据库账号 ID、密码哈希、会话、邀请或申请说明。新增 API 继续使用现有 HttpOnly 会话、服务器真实角色检查与同源检查；未获批、停用和注销账号不能调用。COS 的配置与私人媒体权限保持不变。

## 验收

1. `npm run typecheck`、`npm test`（44 项）、`npm run build`。
2. 在新的临时目录启动测试服务，禁止使用生产或现有本机资料目录：

```sh
ARCHIVE_PUBLIC_DATA=1 ARCHIVE_DATA_DIR=/tmp/naoko-members-disposable-UNIQUE \
CONTRIBUTOR_ADMIN_PASSWORD='member-http-test-password' PORT=3416 npm run start
```

3. `node scripts/verify-member-governance.mjs`，脚本固定使用本机 3416 和测试密码。覆盖匿名与普通成员视图、最小公开字段、申请、重复提交、越权审批、拒绝重提、批准后现有会话管理员权限、注销确认、即时撤销登录/上传、旧投稿保留、不可重新启用和跨站写入拦截。测试账号留在临时库供浏览器验收，绝不能同步到生产。
4. 浏览器实查 `/members`、普通成员状态、管理员账号管理及申请详情。390px 成员与账号管理页无横向溢出。截图见 `docs/screenshots/member-*`，HTTP 记录见 `docs/member-governance-http-qa.json`。
5. 部署前 SQLite 在线备份（包含 WAL），只同步代码并追加迁移；保留服务器 `.env.local`、独立资料目录和所有 COS 对象。重建并重启系统级 `naoko-archive.service`，不启用重复用户级服务，不修改公网端口、域名或 Nginx。正式验证仅登录、读取、退出；不批准、注销或创建真实账号。核对全部现存账号原字段和专辑快照与备份一致。
