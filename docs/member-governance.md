# 社区成员与账号管理

2026-10-22 更新，覆盖此前管理员代注销规则。

- 公开顶栏：主页 → 参与共建 → 社区成员 → 关于 → 搜索。`/members` 只展示已批准、未停用/注销成员的用户名、最多 80 字的简介、角色与加入日期。保留原衬线字体、暖纸色和半透明背景，1000px 及以下采用两行顶栏。
- 管理员在 `/contributor/members` 管理普通贡献者的停用/启用、邀请。停用撤销全部会话，不能登录/编辑/上传；启用后可重新登录。管理员没有代注销入口，旧 `close-user` 请求返回 400，普通成员调用管理 API 返回 403。管理员账号保持现有不允许通过停用修改的规则。
- 所有已登录用户（包括待审及被拒绝的注册申请人）可点击共建顶栏自己的用户名进入 `/contributor/account`。输入完整用户名和当前密码，点击“注销我的账号”。服务端只取会话的本人 ID，拒绝传入其他目标，进行密码校验、同源检查及账号级限流（15 分钟 10 次）。最后一位正常管理员不可注销，需先有另一位获批且启用的管理员。
- 注销保留账号、原用户名、投稿、专辑、版本、媒体、所有权及审计；原用户名不可重新注册。事务中标记注销、撤销全部会话与未用邀请，待审注册和管理员申请转为拒绝。已提交的内容审核消息和修改申请仍保留，管理员按原流程处理。注销不能通过启用恢复。HTTP 响应清除 Cookie，跳转登录页显示成功提示。“退出登录”仅结束当前会话。
- 管理员申请表、申请状态、审核回复及重新申请位于 `/contributor/account#admin-application`，仅获批普通贡献者显示；待审注册用户和管理员不显示申请表。`/members` 是只读目录，不提供成员工作台、申请或管理入口。共建导航的社区成员也指向该只读目录；普通成员访问旧 `/contributor/members` 跳转 `/members`，管理员仍从审批后台进入成员与邀请管理。
- 管理员申请和审核继续使用原服务端流程，已有账号、角色、密码、专辑和 COS 对象不变。本次不新增表或迁移真实资料。
