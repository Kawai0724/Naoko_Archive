# 删除整个专辑

2026-10-22 起以 [内容审核消息](content-review-messages.md) 为准。

删除入口位于版本目录顶部、“编辑专辑”的左边。点击后填写原因并提交审核；管理员自己的申请也不会立即执行。管理员在内容审核中看到“用户申请删除某专辑（原因）”、版本范围，逐条批准或拒绝。

`DELETE /api/contributor/albums/{id}` 现在要求真实会话、同源、`confirm:true`、`expectedRevision`、非空 `reason`，返回 HTTP 202 与待审核 `request`。旧 PATCH delete 行为同步改为申请，不能绕过审核。

只有批准后才软删除整张专辑及所有版本。文件、所有权、批准快照、曲目和历史保留；在“查看已移除”中可以恢复。拒绝不会改变公开内容。详见内容审核说明及隔离 HTTP 验收脚本。
