# 个人账号

顶栏的“个人账号”进入 `/contributor/account`；手机显示带可访问名称的用户图标。访客先登录，登录后直接回账号页；仅允许固定 `next=account`，不接受任意外部跳转地址。原有导航和搜索保留。

账号页显示自己的昵称、登录账号和角色，提供昵称/简介编辑、修改密码，以及折叠的原有注销功能。未设置昵称时显示登录用户名。昵称与简介可留空；分别限制 30 个字符、80 个 Unicode 字符，简介允许换行。本人 Contributor 顶栏同步显示昵称。登录用户名、权限、审批状态、专辑所有权及历史署名不改，社区成员列表在用户名右侧显示简介，空简介不占位；只有获批且活跃成员进入目录。

## 服务端

- `contributor_users` 追加 `nickname`、`bio` 非空字符串列，默认空值；不重建或覆盖已有账号和凭据。迁移可重复执行。
- `GET /api/contributor/account` 仅返回真实会话本人的白名单资料；`PATCH action=profile` 仅接受昵称和简介。所有修改校验同源，拒绝指定其他用户 ID 或附加用户名/角色字段。待审用户也能维护自己的资料，仍不能使用贡献者编辑功能。
- `PATCH action=password` 需要当前密码、新密码及一致的确认值，沿用 12–256 字符限制，拒绝复用当前密码。使用现有 scrypt 加盐哈希，不返回或记录密码。失败请求持久限速，不能借事务回滚重置计数。
- 更新密码、撤销所有本人会话（包括 30 天保持登录）和写入审计在一个事务中提交。失败完整回滚。成功后清除当前 Cookie，提示重新登录；其他账号不受影响。
- 原有停用、注销、权限审批、媒体权限和保持登录机制保留。不更改 COS、服务器网络或现有账号密码。

## 验收

`npm run typecheck`、`npm test`（72 项）、`npm run build`。单元测试覆盖旧库追加迁移、资料持久化/边界、密码及限速、其他账号隔离、旧会话撤销、事务失败回滚。

`scripts/verify-account-profile.mjs` 只接受 `/private/tmp/naoko-sharing-qa.*` 隔离目录，使用现有测试种子账号：先执行 `before-restart`，重启本地应用，再执行 `after-restart`。实际 HTTP 测试包含匿名/伪造 401、跨源 403、越权及字段验证、保存后刷新、密码错误/不一致/过短、密码修改后全部旧令牌失效、旧密码失败/新密码可用、重启持久化、待审成员不提升权限。结果为 `docs/account-profile-http-qa.json`。

浏览器从顶栏点击个人账号，验证访客登录后直接进入本人资料页；用隔离账号保存昵称和 80 字以内简介，刷新后保留并同步顶栏。检查 360、390、768、1440px 无溢出。未通过浏览器修改真实或测试密码；密码更新由隔离 HTTP 测试验证。截图为 `docs/screenshots/personal-account-{header,desktop,mobile}.png`，均使用测试账号。

部署前备份独立生产 SQLite；只同步代码并构建重启现有系统服务。上线只读核对原始密码哈希、角色、会话期限、专辑与媒体记录不变，新字段初始为空。不拿真实账号作资料更新、密码重置或注销测试。

成员简介更新：前后端共同校验 80 字（中文与单个 emoji 均按一个 Unicode 字符计算）。超限保存返回 400；昵称上限仍为 30。公开成员响应仅增加 bio 白名单字段，不含邮箱、凭据或内部审批数据。历史超长简介只在目录中截取前 80 字，不修改数据库原文；本人仍可查看并缩短后保存。桌面和手机保持原有姓名、角色与日期布局，简介置于姓名右侧。截图为 `docs/screenshots/member-bio-{desktop,mobile}.png`。

管理员申请移动至个人账号：已获批的普通贡献者在个人资料下方查看、提交或重新提交管理员申请；待审核时显示状态，拒绝时显示管理员回复。管理员与待审注册账号不展示申请表。沿用现有真实会话、同源保护、修订号及后台审核；不会因移动入口自动提升权限或重写审批记录。社区成员为只读目录，移除工作台/申请入口；成员管理仍由管理员后台进入。验收脚本为 `scripts/verify-account-admin-application.mjs`。

申请入口验收：`docs/account-admin-application-http-qa.json` 记录隔离 HTTP 流程；`docs/account-admin-application-layout-qa.json` 记录 360/390/768/1440px 无溢出。`docs/screenshots/account-admin-application-{desktop,mobile}.png` 为个人账号内的申请区域（测试账号）。浏览器实际提交后显示待审，刷新后仍保留；生产不提交真实申请。

账号功能统一折叠：个人资料、修改密码、自行注销及管理员申请均为默认收起的原生 details/summary，支持鼠标、触屏和键盘独立展开收起。管理员申请必须填写原因，提交后等待管理员审批；资料保存、密码更新和本人注销直接生效，不建立审核申请。密码校验、会话撤销及最后管理员保护保留。截图为 `docs/screenshots/account-disclosures-{desktop,mobile}.png`。

个人账号顶部只保留“← 返回档案馆”，去掉该页的共建导航和重复账号/退出按钮。其他共建页面继续显示原有导航与账号控件；客户端来回切换时随路径正确恢复。服务端身份与权限校验保持不变。
