# 本机目录封面同步

2026-10-21。修复本机 `/discography` 仍显示历史占位图的问题：已批准专辑的文字资料继续来自批准快照，封面单独读取对应版本工作稿。一级封面严格取当前展示的第一项版本；二级和版本详情使用相同封面来源，缺失不借用其他版本。

封面组件通过已有本机 token 读取新增的版本封面接口，接口仍限开发环境、回环地址和同源访问。返回路径仅包含专辑/版本 ID 与修订号，不向页面提供真实存储路径。修订号变化后重新读取图片。不修改私人图片权限、批准快照、歌词或音源；生产模式不启用私人封面预览。

25 项测试通过，含新增的私有封面预览、无跨版本借图、保存快照与草稿内容隔离检查。实际 Scarlet 图片另通过浏览器和文件内容校验验收。
